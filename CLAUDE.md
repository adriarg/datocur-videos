# Datocur Videos

Proyecto multimedia para gestión de videos.

## Installed Skills

- ponytail: Code optimization and YAGNI principle application

## Configuration

This project uses the Ponytail plugin to optimize code by following the "You Aren't Gonna Need It" (YAGNI) principle.

### Ponytail

The Ponytail skill helps reduce unnecessary code while maintaining safety standards. Available commands:
- `/ponytail-review`: Code review with YAGNI focus
- `/ponytail-audit`: Whole-repository analysis
- `/ponytail-debt`: Track deferred work

Reference: https://github.com/dietrichgebert/ponytail
